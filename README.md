# Desafio Farol

Quiz de treinamento em forma de jogo, da Farol Consultoria. Cada pergunta vale mais pontos
quanto mais rápido a pessoa acerta, o pódio atualiza ao vivo e um telão mostra o ranking para
a sala inteira.

Atende vários clientes ao mesmo tempo: cada cliente tem a própria logo, cor, lojas, perguntas
e rodadas, e é escolhido pelo `?c=<identificador>` no link.

- `frontend/`: as telas (jogador, telão, gerente, admin e criação de cliente), publicadas no
  GitHub Pages.
- `supabase/`: banco (migrations) e a Edge Function `api`.

Nenhuma senha fica neste repositório.
